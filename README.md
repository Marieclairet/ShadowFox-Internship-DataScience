### Task 2 – Delhi Air Quality Index (AQI) Analysis
- **Goal:** Examine the major pollutants contributing to Delhi’s poor air quality and identify temporal trends.
- **Dataset:** Public Delhi AQI dataset (daily pollutant readings).
- **Approach:**
  1. Load and preprocess the dataset using **pandas**.
  2. Handle missing values and compute descriptive statistics.
  3. Visualize pollutant trends and relationships using **Seaborn** and **Bokeh**.
- **Key Findings:**
  - **PM2.5** and **PM10** levels are critically high and pose severe health risks.
  - **CO** spikes often coincide with traffic congestion or industrial activities.
  - **O₃** levels vary seasonally, highlighting photochemical pollution patterns.
  - Recommendations: enforce stricter emission controls, encourage green initiatives, and enhance air monitoring systems.
- Full analysis in [Air Quality Index Analysis Documentation (PDF)](Task-2/Air%20Quality%20Index%20Analysis%20Documentation.pdf)
